## What actually works (ideas we adapted legally)

1. **Output early and often**: Speak, Praktika, Loora. → *Talk to me*, *Find the words*, *Speak without fear*; conversation time is the main metric on Home/Progress.
2. **Feedback after, not during** (Loora-style). → Corrections arrive in a post-conversation review; modes (Friendly / Teacher / Immersion / Beginner / Strict) tune interruption.
3. **Phoneme-specific drills** (ELSA). → Minimal pairs + IPA + slow playback today; phoneme scoring is a Phase 3 goal only if a free model can do it honestly.
4. **Streaks without shame** (Duolingo). → Streak is shown but secondary; no loss aversion, no guilt notifications.
5. **Spaced repetition** (Anki-style, used by many). → Our SRS requires *production* (typed/spoken) for ACTIVE/MASTERED states.

## Where we can be better

- **One learner model across everything**: mistakes from conversation feed the SRS, plan and notifications (competitors mostly keep modules separate).
- **Free and offline-first**: no subscription; core learning works with no network.
- **Active-recall focus for a French speaker**: "How do I say…?" always one tap away; French support slider; false-friend and "frequent French-speaker mistakes" rules.
- **Transparent, non-promissory progress**: only measured facts ("You spoke 42 minutes this week"), no "fluent in 30 days".
